# Recorded validation results

These CSV files were extracted from the uploaded notebook's **existing saved execution output**; the model was not retrained during repository packaging.

- `best_validation_metrics.csv`: exact printed metrics for the best-WER checkpoint (epoch 95).
- `validation_history.csv`: training and validation WER/CER at epochs 5, 10, ..., 100.

All values are **percentages**. They are **not** hidden-test results and are not necessarily scored using the competition's official text normalization.
